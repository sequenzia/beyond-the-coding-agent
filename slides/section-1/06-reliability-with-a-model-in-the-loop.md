## Talk track

[0:00] That changes what we need to establish before calling the system reliable.

[0:06] A response can look valid and still be wrong. A successful run tells us that the system worked on that attempt. It does not tell us how consistently it will work across its intended use.

[0:23] **And consistency alone is not correctness. A model can repeat the same mistake.**

[0:30] With an agent, those judgments can also select tools and influence what happens next. Errors can affect later steps.

[0:40] That is why **a compelling prototype is not evidence of production readiness.**
