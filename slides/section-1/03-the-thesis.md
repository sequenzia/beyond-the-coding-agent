## Talk track

[0:00] Slide up. Read the two sentences, slowly, before anything else.

**Using AI makes you an AI-enabled software engineer. Engineering systems that depend on AI makes you an AI engineer.**

[0:08] This is not a new distinction. swyx describes three types of AI engineer: a software engineer enhanced by AI, a software engineer building AI products, and a software engineer that is itself an AI. **The coding agent is the first type. This talk is about the second.**

[0:24] **Built on software engineering, not instead of it.** Carnegie Mellon's Software Engineering Institute defines the field as systems engineering, software engineering, computer science, and human-centered design, combined.

[0:34] **And not machine learning engineering.** ML engineers build models. AI engineers build products around models someone else trained. Product-first, not model-first, in Chip Huyen's framing.

[0:42] **The title is three years old. The discipline is what we are here to define.**

[0:45] Advance to slide 4.

Cuttable if short on time: the four disciplines in the SEI definition; "in Chip Huyen's framing."

Backup for questions, not spoken: swyx's own name for the first type is the "AI enhanced engineer," which is this talk's "AI-enabled software engineer" under another name. If the room does not know swyx, add "who runs the AI Engineer conferences" after his name.
