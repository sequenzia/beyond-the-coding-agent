# Slide 6: Transition

Beat 1.6 Transition. Section 1. Time 0:15. Builds: 0.

## On the slide

A terminal window. Dark, full screen, empty except for a prompt and a blinking cursor. No tool name, no logo, no text.

## Layout and visual

- The frame should read as "a coding agent, just launched" to anyone in the room, without naming one. A bare prompt character and a cursor does that. Codex CLI and Devin CLI both start from something that looks like this.
- Vendor-neutral on purpose. Four logos would say "these tools"; an empty terminal says "your tool."
- This is the surface. Slide 7 is what is underneath it. Cut straight from this slide to the diagram, no transition effect, so the diagram lands as a reveal.
- If the deck template cannot do a full-screen terminal, fall back to the sentence "Let's open up the tool you used this morning" alone on the slide. The terminal is better because the line is then spoken over an image rather than read off a screen.

## Talk track

[0:00] Let the terminal sit for a moment. Then:

**Let's open up the tool you used this morning.**

[0:15] Advance to slide 7.

The fifteen seconds is deliberate. It is the breath between the five-minute setup and the twenty-five-minute body. Do not fill it.
